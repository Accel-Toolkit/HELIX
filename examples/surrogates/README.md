# Surrogate-element training drivers

End-to-end training pipelines for HELIX surrogate elements
(see `docs/plans/surrogates.md`).  Each driver here:

1. Loads a TraceWin lattice.
2. Picks a specific element to surrogate.
3. Generates (input, output) samples by passing them through the
   real HELIX element tracker.
4. Trains the MLP head.
5. Saves weights + a reproducibility manifest (`metadata.json`)
   under `linac_gen/surrogates/weights/<lattice-hash>/<element>/`.

## `train_fieldmap_mlp.py` — M2 envelope-mode FieldMap3D driver

Trains an MLP surrogate for the first `FIELD_MAP` element in a
loaded lattice (default: PIP-II MEBT buncher #1, name `FMAP_001`,
240 mm QWR, 162.5 MHz).

The surrogate predicts the linearised 6×6 transfer matrix
`fitted_matrix(ref)` given `(w_kin, β, γ, ke, phase)`.  Training data
is generated by Latin Hypercube sampling over (incoming kinetic
energy + element `ke` ±20 % + element `phase` ±20°), with the
element's own RK4-based `fitted_matrix(ref)` as ground truth.

### Smoke cycle (~ 1 minute on CPU)

```bash
PYTHONPATH=. python examples/surrogates/train_fieldmap_mlp.py \
    --samples 200 --epochs 40
```

Just exercises the pipeline; will not meet the M2 acceptance gates.

### Full M2 acceptance run (~ hours)

```bash
PYTHONPATH=. python examples/surrogates/train_fieldmap_mlp.py \
    --samples 50000 --epochs 300 --hidden 128,128,128
```

Acceptance gates (from `docs/plans/surrogates.md`):

* Per-element matrix Frobenius rel.diff &lt; 0.5 % in scope.
* Symplecticity defect `‖MᵀSM − S‖_F / 6 < 1e-3`.

### Output

* `linac_gen/surrogates/weights/<hash>/<element>/weights.pt` — torch
  state dict.
* `linac_gen/surrogates/weights/<hash>/<element>/metadata.json` —
  reproducibility manifest: training seed, HELIX HEAD sha, lattice
  hash, scope bounds, normalisation constants, val MAPE.

### Custom lattice / element

```bash
PYTHONPATH=. python examples/surrogates/train_fieldmap_mlp.py \
    --lattice path/to/your.dat \
    --samples 10000 --epochs 200 \
    --w-kin-range 2.0,2.5 \
    --ke-rel 0.15 --phase-rel-deg 15
```

Currently the driver picks the first `FieldMap3D` it finds — extend
the script (`_find_first_field_map`) to pick by name/index if you
have a multi-cavity lattice.

## Loading a trained surrogate

```python
from linac_gen.surrogates.training import load_surrogate
from linac_gen.surrogates.base import SurrogateFieldMap
from linac_gen.surrogates import registry

mlp, meta = load_surrogate("linac_gen/surrogates/weights/<hash>/<elem>/")
surr = SurrogateFieldMap(wrapped_element, mlp, meta)
registry.register(surr)   # M3 envelope hook (forthcoming) consults this
```
