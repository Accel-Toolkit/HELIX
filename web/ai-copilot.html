Built-in AI copilot

Talk to the simulator.

HELIX ships an optional assistant that drives the same audited tools you use by hand — with a three-tier safety gate and a replayable ledger of every call.

Three-tier safety. Reads run freely. Compute and mutate actions echo the exact resolved call and wait for your confirmation. Every call is written to a JSONL ledger you can replay.
46 tools Offline voice MCP server Keyless via Claude

What it can do

A copilot that knows the machine.

Fully offline voice

Say “HELIX” to wake it (silero-VAD + faster-whisper, accent-tolerant). Talk over it to interrupt, keep talking as it answers — no cloud audio, ever.

Instant commands

“status”, “show the RMS plot”, tour “next” — unambiguous read-only requests execute in milliseconds, no model round-trip.

Tour & drills

A 15-station walkthrough of the workbench, plus hidden-fault exercises where the assistant coaches you without knowing the answer itself.

Sandboxed Python

Analysis code runs in an isolated interpreter with your result arrays injected; plots come back inline.

Gradient sensitivities

One autograd pass ranks every quad, solenoid and dipole by exact d(σexit)/d(knob).

Vision

It can look at your plots and describe what it sees.

Run watching

Every finished run is inspected for transmission drops, σ blow-ups and baseline drift — it speaks up when something moved.

Audited & replayable

The three-tier gate resolves each call before it runs; the JSONL ledger records every one for replay.

Bring your own brain

Three backends — including fully local.

Pick the reasoning engine that fits your environment. No API key and no network? The assistant is still there, text-first, and the app is unaffected.
